## Problems found and fixed

Fuzzing found two importer bugs on its first run:

- A GNS3 node without a `name` produced a device with no hostname.
- A non-string Containerlab link endpoint (for example `1`) threw a `TypeError`.

Imported JSON and YAML are now type-checked value by value. Also fixed: the nightly fuzz job's test
filter matched no test names, so it had been running nothing; and YAML warnings no longer go to the
console.
