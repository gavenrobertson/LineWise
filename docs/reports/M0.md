## Decisions and ADRs

No new ADRs. New entries in [decisions-log.md](../decisions-log.md):

- Work from the earlier session continues on its history; milestone tags go on verified commits.
- Tauri `freezePrototype` is off (it broke d3-color and left the window blank).
- License allowlist additions (MIT-0, 0BSD, Unlicense, CDLA-Permissive-2.0).
- `THIRD_PARTY_NOTICES.md` is a build output shown under Help → About → Licenses.
- The smoke test bypasses native dialogs with a debug-only `LINEWISE_SMOKE_DIR` hook.
- LF line endings via `.gitattributes`.
- The Windows smoke test attaches msedgedriver to a smoke-only build that opens WebView2's
  debugging port itself, because the runner's WebView2 ignores the port passed through the
  environment.

## Problems found and fixed

- The native window rendered blank (Tauri `freezePrototype` against d3-color).
- The SVG exporter wrote an embedded asset's MIME type into markup unescaped; a hand-edited file
  could inject attributes into an exported SVG. Assets now pass an allowlist (NFR-SEC-03).
- Windows: `pnpm` could not be spawned from Node scripts; WebView2 WebDriver sessions could not be
  created on the runner image.

## Known issues

- Releases are unsigned until the owner sets up signing (REL-01, REL-02) and the updater key
  (REL-10..12).
- macOS has no WKWebView WebDriver, so native macOS checks are manual (release checklist, M6).
