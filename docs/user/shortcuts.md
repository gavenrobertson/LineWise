# Keyboard shortcuts

**Help → Keyboard Shortcuts** (`Ctrl+/`) shows this list in the app. On macOS, `Ctrl` is `⌘`,
`Alt` is `⌥` and `Shift` is `⇧`; the exceptions are noted below. Commands without a shortcut, such
as **Insert zone** or **VLAN manager…**, are in the command palette (`Ctrl+K`).

## File

| Action        | Shortcut       |
| ------------- | -------------- |
| New diagram   | `Ctrl+N`       |
| Open…         | `Ctrl+O`       |
| Save          | `Ctrl+S`       |
| Save as…      | `Ctrl+Shift+S` |
| Import…       | `Ctrl+I`       |
| Export…       | `Ctrl+E`       |
| Print…        | `Ctrl+P`       |
| Close diagram | `Ctrl+W`       |

## Edit

| Action                      | Shortcut                   |
| --------------------------- | -------------------------- |
| Undo                        | `Ctrl+Z`                   |
| Redo                        | `Ctrl+Shift+Z` or `Ctrl+Y` |
| Cut                         | `Ctrl+X`                   |
| Copy                        | `Ctrl+C`                   |
| Paste                       | `Ctrl+V`                   |
| Duplicate                   | `Ctrl+D`                   |
| Delete                      | `Delete` or `Backspace`    |
| Select all                  | `Ctrl+A`                   |
| Select all of the same type | `Ctrl+Shift+A`             |
| Copy style                  | `Ctrl+Alt+C`               |
| Paste style                 | `Ctrl+Alt+V`               |
| Find…                       | `Ctrl+F`                   |
| Preferences…                | `Ctrl+,`                   |

On macOS, Preferences is **LineWise → Settings…** (`⌘,`).

## Window and Help

| Action             | Shortcut         |
| ------------------ | ---------------- |
| Next diagram       | `Ctrl+Tab`       |
| Previous diagram   | `Ctrl+Shift+Tab` |
| Keyboard shortcuts | `Ctrl+/`         |

On macOS, next and previous diagram use the Control key: `⌃Tab` and `⌃⇧Tab`.

## Canvas

| Action                        | Keys                                                 |
| ----------------------------- | ---------------------------------------------------- |
| Pan                           | `Space` + drag, or drag with the middle mouse button |
| Add to selection              | `Shift` or `Ctrl` + click                            |
| Nudge selection               | Arrow keys (with `Shift`: 10 times further)          |
| Pan, with nothing selected    | Arrow keys (with `Shift`: further)                   |
| Move focus to nearest device  | `Alt` + arrow keys                                   |
| Edit hostname                 | `Enter`                                              |
| Link from focused device      | `L`                                                  |
| Clear selection and highlight | `Esc`                                                |

`Tab` moves through the toolbar, sidebar, canvas, Inspector and status bar, and through the
devices on the canvas. A device that gets focus this way becomes the selection when you press
`Enter`, `Space` or `L`.

## In panels and dialogs

| Where                  | Keys                                                            |
| ---------------------- | --------------------------------------------------------------- |
| Device library search  | `Enter` places the best match; `Down arrow` moves into the list |
| Connect dialog         | `Enter` connects                                                |
| Find                   | `Enter` next hit, `Shift+Enter` previous hit, `Esc` closes      |
| Text, notes and shapes | Double-click to edit; `Ctrl+Enter` finishes, `Esc` cancels      |
| Page tabs              | `F2` renames the page                                           |
| Path highlight         | `Esc` cancels picking the devices                               |
| Presentation mode      | `Page Down`, `Page Up` or `Space` changes page; `Esc` leaves    |

## While typing in a field

When a text field outside a dialog has focus, these shortcuts still work: New, Open, Save, Save as,
Import, Export, Print, Command palette, Find and Keyboard shortcuts. The field's edit is saved
first. Other shortcuts, such as `Ctrl+Z` and `Ctrl+C`, act on the text field instead of the
diagram.
