| 2026-10-10 | Work from the earlier session (M0–M5 largely built, no CI, no tags) is continued on top of its history rather than restarted. | 2026-10-10 | The license gate also allows MIT-0, 0BSD, Unlicense and CDLA-Permissive-2.0 for shipped code, and Python-2.0, CC-BY-4.0/3.0 and BlueOak-1.0.0 for dev-only tools. | 2026-10-10 | `THIRD_PARTY_NOTICES.md` is a build output (generated by the desktop `build` script, git-ignored) and is bundled into the app; Help → About → Licenses shows it offline.                                                                                                                                                                     | Keeps the notices exactly in sync with the lockfiles without a large generated file in Git.                                                                                                                                                                                                                                            |

| 2026-10-10 | Line endings are normalised to LF by `.gitattributes`.                                                                                                                                                                                                                                                                                       | Windows CI checkouts otherwise get CRLF, which breaks the Prettier check, golden snapshots and byte-identical save tests.                                                                                                                                                                                                              |
| 2026-10-10 | FR-APP-02 is met with document tabs in the main window on both OSes; each tab keeps its own Editor (undo history), page, selection and validation results. Separate macOS windows per diagram are not built in v1.                                                                                                                           | The spec allows "its own window (macOS) or tab (both)"; one window with tabs works the same on both OSes and keeps the single Tauri window and capability set.                                                                                                                                                                         |
| 2026-10-10 | On Windows CI the native smoke test attaches msedgedriver to the app (`debuggerAddress`) instead of letting tauri-driver launch it. A smoke-only build (`tauri.smoke.conf.json`) opens WebView2's remote debugging port from its own config; it is built after the debug installers and never shipped or uploaded. Linux keeps tauri-driver. | The WebView2 runtime on GitHub's Windows runners (v153) ignores the `--remote-debugging-port` msedgedriver passes through `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS`, so tauri-driver sessions fail with "DevToolsActivePort file doesn't exist" (actions/runner-images#14738). A config test keeps the port out of every shipped config. |
| 2026-10-10 | Zoom to fit never zooms past 100%.                                                                                                                                                                                                                                                                                                           | React Flow's initial fit ran when the first device was placed on a blank page and zoomed to 400%, so devices looked huge and covered each other's handles.                                                                                                                                                                             |
| 2026-10-10 | No vendor-model templates ship until their port layouts are read from the vendor's public datasheet; search-engine summaries are not used as a source, even for `verified: false` templates.                                                                                                                                                 | The build environment's network policy blocks every vendor site, and FR-TPL-03 forbids invented port counts. Shipping second-hand data would put unverifiable hardware specs in users' diagrams. Tracked in docs/HUMAN-TODO.md.                                                                                                        |
| 2026-10-10 | Milestone tags are created locally on the CI-verified commit and listed with their SHAs and CI runs in docs/HUMAN-TODO.md for the owner to push. Each tag gets its own version-bump commit (`chore(release): x.y.z`) so `release.yml`'s version check and release notes match the tag.                                                       | The environment's Git proxy only accepts pushes to the working branch (tag pushes return 403), and `release.yml` builds only from an existing tag.                                                                                                                                                                                     |
| 2026-10-10 | M2, M3 and M4 were accepted together: their release commits (0.2.0, 0.3.0, 0.4.0) were stacked and verified by one CI run on the 0.4.0 head. The earlier two differ from it only in version numbers and CHANGELOG.                                                                                                                           | Every push cancels the branch's running CI, and each run takes about 8 minutes; the code under test is identical, so one green run covers all three tags.                                                                                                                                                                              |
| 2026-10-10 | Accessible colors: Link teal stays the accent for icons, borders and focus; accent-colored text and filled buttons use teal-700 (`#0F766E`) in light mode. The dark theme's base is Ink with Ink raised panels, Link teal fills with Ink text and `#2DD4BF` accent text. The welcome wordmark is 24 px so Link teal "Wise" is large text.    | WCAG AA (NFR-A11Y-04) and BRD-05: white on `#0D9488` is 3.74:1, below 4.5:1 for normal text. axe-core with contrast checks now runs in E2E in both themes.                                                                                                                                                                             |
| 2026-10-10 | The drag benchmark (NFR-PERF-04) drags the device nearest the middle of the canvas and counts frames only while it moves; the press (which selects it) and the drop (which commits it to history) are left out.                                                                                                                              | It used the first device in the DOM, a core switch at the edge of the view, so React Flow auto-panned the whole canvas for the first moves and the number measured panning. The press and the drop are single updates, the same kind of work as a property edit, which has its own 50 ms budget.                                       |
| 2026-10-10 | Device connection handles mount only on the device under the pointer; every device and off-page reference has one hidden, zero-size anchor handle at the link end point, and links take their ends from React Flow's handle position instead of subscribing to both nodes.                                                                   | Each handle and each `useInternalNode` is a store subscription that re-ran on every pointer move: about 5,600 with 500 devices and 800 links. Off-page references had no handle at all, so React Flow never drew their links (FR-CAN-12); an E2E test now checks one is drawn.                                                         |
| 2026-10-11 | The interface follows the OS text size through the web view's own zoom (`set_ui_scale`); on Windows the factor is read from `HKCU\Software\Microsoft\Accessibility\TextScaleFactor`. Preferences → Interface size overrides it (90–200%). macOS has no system text size for web views, so it stays at 100% unless chosen.                    | NFR-A11Y-04 asks the UI to scale with OS text size. The UI is laid out in CSS pixels; native zoom scales everything and keeps React Flow's pointer math right, which CSS `zoom` does not. WebView2 does not apply the Windows text size by itself.                                                                                     |
| 2026-10-11 | Default VLAN colors are the Okabe–Ito color-blind-safe set (without yellow), with luminance clamped so each has 3:1 against both canvases, assigned in VLAN order within a document.                                                                                                                                                         | NFR-A11Y-03. The previous palette put green next to red. Colors are never the only signal: L2 links carry their VLAN label, problems a glyph.                                                                                                                                                                                          |
| 2026-10-11 | Problem badges carry a glyph (✕ error, ▲ warning, i information) on devices and at the middle of links; an error link in an export gets the same ✕.                                                                                                                                                                                          | NFR-A11Y-03: severity was shown by color alone.                                                                                                                                                                                                                                                                                        |
| 2026-10-11 | In the outline, Enter on a link peer selects the link (whose inspector edits style and bend points); bend points can also be added, moved and removed as numbers in the inspector, zones and annotations sized there, and arrow keys pan the canvas when nothing is selected.                                                                | FR-KEY-02: these canvas actions were mouse-only.                                                                                                                                                                                                                                                                                       |
| 2026-10-11 | Starter diagrams assign each device to the innermost zone drawn around it, as dropping it there does.                                                                                                                                                                                                                                        | Starters drew zones around devices without setting `zoneId`, so the outline showed empty zones and zone-scoped features missed them.                                                                                                                                                                                                   |
| 2026-10-11 | Imported HTML (draw.io labels) is reduced to plain text in the parser and rendered as text; it is never rendered as HTML, so no DOMPurify pass is needed for it. SVG (icons, icon packs, images) goes through DOMPurify's SVG profile.                                                                                                       | NFR-SEC-03 asks for sanitizing before rendering or embedding. The parsers are DOM-free by design; plain text is stricter than sanitized markup.                                                                                                                                                                                        |
| 2026-10-11 | Icon-pack zips: at most 20 MB, 2,000 entries and 64 MB expanded; entries over 1 MB, or with parent, absolute or drive paths, are skipped; fflate inflates into the declared size, so a header cannot understate its size.                                                                                                                    | NFR-SEC-04 (zip-slip, zip bombs). Nothing from a pack is written to disk, but the limits keep memory bounded.                                                                                                                                                                                                                          |
