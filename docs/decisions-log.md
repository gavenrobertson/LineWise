# Decisions log

Small decisions made where the spec was open. Larger ones are ADRs in `docs/adr/`.

| Date       | Decision                                                                                                                                                                                                                                                     | Why                                                                                                                                                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2026-10-09 | Brand assets live in `packages/brand/` (spec section 15, BRD-01).                                                                                                                                                                                            | Keeps logo masters and fonts versioned with the code and reusable by the docs site.                                                                                                                                                              |
| 2026-10-09 | Entity IDs are UUID v7 generated in `core` with a small dependency-free implementation; tests inject a deterministic ID source.                                                                                                                              | Time-ordered IDs sort well in the file; deterministic IDs make golden tests stable.                                                                                                                                                              |
| 2026-10-09 | JSON keys are sorted recursively on save; entity arrays sorted by `id`; `pages` keep their `order` field and are sorted by it.                                                                                                                               | FR-FMT-01 stable diffs.                                                                                                                                                                                                                          |
| 2026-10-09 | Pin TypeScript to 6.0.x instead of 7.0 (latest).                                                                                                                                                                                                             | typescript-eslint 8.71 supports TypeScript `>=4.8.4 <6.1.0`; TS 7 (native compiler) has no JS API yet. Revisit when typescript-eslint supports TS 7. Renovate is configured not to bump the major automatically.                                 |
| 2026-10-10 | Work from the earlier session (M0–M5 largely built, no CI, no tags) is continued on top of its history rather than restarted. Milestones are re-audited in order; each tag is placed on the commit where that milestone's acceptance criteria were verified. | Rebuilding finished, tested code would add risk without value; the audit keeps the milestone gates meaningful.                                                                                                                                   |
| 2026-10-10 | Tauri `app.security.freezePrototype` is off.                                                                                                                                                                                                                 | With it on, d3-color (used by React Flow's zoom) throws "Attempted to assign to readonly property" while defining classes, so the desktop UI never rendered. Found by the new tauri-driver smoke test. The strict CSP (NFR-SEC-02) is unchanged. |
| 2026-10-10 | The license gate also allows MIT-0, 0BSD, Unlicense and CDLA-Permissive-2.0 for shipped code, and Python-2.0, CC-BY-4.0/3.0 and BlueOak-1.0.0 for dev-only tools. GPL/AGPL/LGPL/SSPL/unknown stay blocked.                                                   | All are permissive (equal to or looser than MIT); dev-only tools are never bundled. OSS-02's intent is "permissive only".                                                                                                                        |
| 2026-10-10 | `THIRD_PARTY_NOTICES.md` is a build output (generated by the desktop `build` script, git-ignored) and is bundled into the app; Help → About → Licenses shows it offline.                                                                                     | Keeps the notices exactly in sync with the lockfiles without a large generated file in Git.                                                                                                                                                      |
| 2026-10-10 | The native smoke test bypasses OS file dialogs with `LINEWISE_SMOKE_DIR`, honoured only in debug builds (`cfg(debug_assertions)`).                                                                                                                           | WebDriver cannot drive native dialogs; release builds compile the hook out.                                                                                                                                                                      |
| 2026-10-10 | Line endings are normalised to LF by `.gitattributes`.                                                                                                                                                                                                       | Windows CI checkouts otherwise get CRLF, which breaks the Prettier check, golden snapshots and byte-identical save tests.                                                                                                                        |
| 2026-10-10 | FR-APP-02 is met with document tabs in the main window on both OSes; each tab keeps its own Editor (undo history), page, selection and validation results. Separate macOS windows per diagram are not built in v1.                                           | The spec allows "its own window (macOS) or tab (both)"; one window with tabs works the same on both OSes and keeps the single Tauri window and capability set.                                                                                   |
